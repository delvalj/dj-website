# Fotos de la web

Aquí van las fotos **originales, en color normal**. El efecto verde (duotono + grano) lo pone la web
automáticamente: no hay que editarlas.

## Portada: `hero.jpg`
- Nombre exacto: `hero.jpg` (también vale `hero.png` o `hero.webp`).
- Mínimo 2400 px de ancho, horizontal.
- Mejor si tiene "aire" alrededor del motivo: en el móvil la foto se recorta en vertical.
  Si el recorte no queda bien, se ajusta `position` de la portada en `src/config/site.ts`
  (por ejemplo `"50% 30%"` para quedarse con la parte de arriba).
- Para cambiar la foto: sustituye el archivo por otro con el mismo nombre. Nada más.
- Mientras no exista, la web muestra un degradado oscuro con la etiqueta "PLACEHOLDER".

## About: `about.jpg` (fase 5)
- Retrato o foto en directo, en vertical.
